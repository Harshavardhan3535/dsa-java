# DSA in Java

My LeetCode practice in Java. I solve each problem on paper first, then code it, then write short notes on the idea and my mistakes.

| # | Problem | Approach | Time |
|---|---------|----------|------|
| 01 | [Two Sum](01-two-sum) | HashMap, one pass | O(n) |
| 02 | [Contains Duplicate](02-contains-duplicate) | HashSet / Sorting | O(n) / O(n log n) |
| 03 | [Valid Anagram](03-valid-anagram) | Sorting / HashMap count | O(n log n) / O(n) |
| 04 | [Group Anagrams](04-group-anagrams) | HashMap, sorted word as key | O(n k log k) |
| 05 | [Top K Frequent Elements](05-top-k-frequent-elements) | HashMap count + sort by count | O(n + m log m) |
| 06 | [Product of Array Except Self](06-product-of-array-except-self) | Prefix and suffix products | O(n) |
| 07 | [Longest Consecutive Sequence](07-longest-consecutive-sequence) | HashSet / Sorting | O(n) / O(n log n) |
| 08 | [Valid Palindrome](08-valid-palindrome) | Reverse and compare / Two pointers | O(n^2) / O(n) |
| 09 | [Two Sum II](09-two-sum-ii) | Two pointers on sorted array | O(n) time, O(1) space |
