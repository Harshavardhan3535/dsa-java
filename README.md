# DSA in Java

My LeetCode practice in Java. I solve each problem on paper first, then code it, then write short notes on the idea and my mistakes.

| # | Problem | Approach | Time |
|---|---------|----------|------|
| 01 | [Two Sum](01-two-sum) | HashMap, one pass | O(n) |

| 04 | [Group Anagrams](04-group-anagrams) | HashMap, sorted word as key | O(n k log k) |
